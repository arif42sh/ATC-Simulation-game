# SkyATC AI - Custom Audio Files Directory

You can add your custom sound files (`.mp3`, `.wav`, or `.ogg`) directly into this folder.
The game will automatically detect and load them on startup!

### Recommended File Names:
- `click.mp3` - Button click & menu selection sound
- `landing.mp3` - ATC runway assignment / clearance chime
- `touchdown.mp3` - Touchdown fanfare when aircraft safely lands
- `emergency.mp3` - Mayday / critical fuel / engine alarm siren
- `warning.mp3` - Caution tone for short runway / conflict warning
- `victory.mp3` - Level complete celebration fanfare
- `ambience.mp3` - Background airport ambience or radio chatter loop
